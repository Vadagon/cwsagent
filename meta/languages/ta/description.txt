உங்கள் பட்டியலை நிரப்புங்கள். ஒரு தொகுப்பு. எல்லா மொழிகளும். Chrome மற்றும் Edge.

உங்கள் பட்டியலை நிரப்புங்கள்
ZIP அல்லது கோப்புறையை ஏற்றவும் அல்லது ExtensionTower இணைத்து Sync தேர்ந்தெடுக்கவும். திறந்த ஸ்டோர் தாவலின் ஆதரிக்கப்படும் புலங்களை நிரப்பவும்.

ஒரு தொகுப்பு. எல்லா மொழிகளும்.
ஒவ்வொரு மொழியின் விளக்கத்தையும் திரைப்பிடிப்புகளையும் ஒன்றாக வைக்கவும். பதிவேற்றிய நீட்சியில் உள்ள மொழிகளை ஸ்டோர் வழங்கும்.

Chrome மற்றும் Edge
Chrome Web Store கன்சோல் அல்லது Microsoft Edge Partner Center பயன்படுத்தவும். ஒவ்வொரு வரைவையும் நீங்களே சரிபார்த்து சேமிக்கவும்.

திருத்தும் முன் ஏற்றுமதி
Chrome உரை மற்றும் படங்களைத் திருத்தக்கூடிய தொகுப்பாக ஏற்றுமதி செய்யவும். கன்சோல் புள்ளிவிவரங்கள் மற்றும் உதவி செய்திகள் விருப்பமானவை.

இறுதிச் சேமிப்பு உங்கள் கையில்
CWSAgent படிவங்களை நிரப்பும். தானாகச் சேமிக்கவோ சமர்ப்பிக்கவோ சான்றுறுதிகளைத் தேர்வுசெய்யவோ விலை அல்லது தெரிவுநிலையை மாற்றவோ செய்யாது.

தொகுப்புகள், வரலாறு மற்றும் அமைப்புகள் உலாவியில் இருக்கும். ஏற்றுமதி கோப்புகள் கணினியில் பதிவிறங்கும். உதவி செய்திகளில் தனிப்பட்ட தகவல்கள் இருக்கலாம்: கோப்புகளைத் தனியாக வைத்திருங்கள்.

ExtensionTower இணைப்பு விருப்பமானது. API சாவி நீட்சியின் IndexedDBயில் இருக்கும்; பின்னணி செயல்முறை மட்டுமே பயன்படுத்தும், ஸ்டோர் பக்கத்திற்கு அனுப்பாது. இணைப்பு extensiontower.comஇலிருந்து பட்டியல் மற்றும் தொகுப்புகளைப் படிக்கும்; Sync படங்களையும் பதிவிறக்கும். பட ஏற்றுமதி கன்சோலின் பட சேவையகங்களை அணுகும். செயல்கள் உங்கள் Google அல்லது Microsoft அமர்வைப் பயன்படுத்தும். பகுப்பாய்வு அல்லது கண்காணிப்பு சேவை இணைக்கப்படவில்லை.

Chromeக்கு --apps-gallery-url உடன் தனி வெளியீட்டு சுயவிவரம் தேவை; வழிகாட்டியைப் பாருங்கள். Edgeக்கு சிறப்புச் சாளரம் தேவையில்லை. உள்ளூர் இறக்குமதி இலவசம்; Syncக்கு அந்தப் பட்டியலின் ExtensionTower தொகுப்பு தேவை. Google அல்லது Microsoft உடன் தொடர்பில்லை.
