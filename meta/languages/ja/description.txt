CWSAgent – ストア掲載情報の自動入力・抽出

Chrome と Edge の掲載情報を入力・書き出し。説明文、翻訳済みスクリーンショット、宣伝画像、プライバシー回答に対応。

掲載情報を入力
ZIP やフォルダを読み込むか、ExtensionTower に接続して Sync を選択。開いているストアタブの対応項目を入力します。

1つのパッケージで各言語へ
言語ごとの説明文と画像をまとめて管理。ストアではアップロードした拡張機能に含まれる言語を選べます。

Chrome と Edge に対応
Chrome Web Store の開発者コンソールや Microsoft Edge Partner Center で利用。各下書きを自分で確認して保存します。

編集前に書き出し
Chrome の文章と画像を編集可能なパッケージに書き出し。コンソール統計やサポートメッセージも任意で書き出せます。

保存するのはあなた自身
CWSAgent はフォームを入力します。自動保存・送信、認証項目のチェック、価格や公開範囲の変更は行いません。

パッケージ、履歴、設定はブラウザ内に保存。書き出したファイルはパソコンにダウンロードされます。個人情報を含む可能性があるサポートファイルは非公開で保管してください。

ExtensionTower への接続は任意です。API キーは拡張機能の IndexedDB に保存され、バックグラウンド処理のみが使用し、ストアページには渡しません。extensiontower.com から拡張機能一覧とパッケージを読み取り、Sync では画像も取得します。画像抽出時はコンソールの画像サーバーに接続します。ストア操作は自分の Google または Microsoft セッションを使います。分析・追跡サービスは組み込まれていません。

Chrome では --apps-gallery-url 付きの専用公開プロファイルが必要です。導入ガイドを参照してください。Edge は専用ウィンドウ不要。ローカルパッケージの読み込みは無料で、Sync は対象掲載情報の ExtensionTower パッケージが必要です。Google・Microsoft とは無関係です。
