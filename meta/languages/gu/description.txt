CWSAgent – સ્ટોર લિસ્ટિંગ ભરો અને નિકાસ કરો

Chrome અને Edge લિસ્ટિંગ ભરો અને નિકાસ કરો: વર્ણન, અનુવાદિત સ્ક્રીનશૉટ, પ્રચાર ચિત્રો અને ગોપનીયતાના જવાબો.

તમારું લિસ્ટિંગ ભરો
ZIP કે ફોલ્ડર લોડ કરો, અથવા ExtensionTower જોડીને Sync પસંદ કરો. ખુલ્લા સ્ટોર ટૅબનાં સમર્થિત ક્ષેત્રો ભરો.

એક પેકેજ. બધી ભાષાઓ.
દરેક ભાષાનું વર્ણન અને સ્ક્રીનશૉટ સાથે રાખો. સ્ટોર અપલોડ કરેલા એક્સટેન્શનની ભાષાઓ આપે છે.

Chrome અને Edge
Chrome Web Store કન્સોલ કે Microsoft Edge Partner Center વાપરો. દરેક ડ્રાફ્ટ જાતે તપાસીને સેવ કરો.

ફેરફાર પહેલાં નિકાસ કરો
Chromeનાં લખાણ અને ચિત્રો સંપાદિત કરી શકાય તેવા પેકેજમાં નિકાસ કરો. કન્સોલ આંકડા અને સહાય સંદેશા વૈકલ્પિક છે.

છેલ્લું સેવ તમારા હાથમાં
CWSAgent ફોર્મ ભરે છે. આપમેળે સેવ કે સબમિટ કરતું નથી, પ્રમાણન પસંદ કરતું નથી કે ભાવ અને દૃશ્યતા બદલતું નથી.

પેકેજ, ઇતિહાસ અને સેટિંગ બ્રાઉઝરમાં રહે છે. નિકાસ ફાઇલો કમ્પ્યુટર પર ડાઉનલોડ થાય છે. સહાય સંદેશા ખાનગી હોઈ શકે: ફાઇલો ગુપ્ત રાખો.

ExtensionTower જોડાણ વૈકલ્પિક છે. API કી એક્સટેન્શનના IndexedDBમાં રહે છે અને માત્ર પૃષ્ઠભૂમિ પ્રક્રિયા વાપરે છે, સ્ટોર પેજ નહીં. જોડાણ extensiontower.comથી યાદી અને પેકેજ વાંચે છે; Sync ચિત્રો પણ ડાઉનલોડ કરે છે. ચિત્ર નિકાસ કન્સોલના ચિત્ર સર્વર સાથે જોડાય છે. ક્રિયાઓ તમારા Google કે Microsoft સત્રનો ઉપયોગ કરે છે. કોઈ વિશ્લેષણ કે ટ્રૅકિંગ સેવા જોડાયેલી નથી.

Chrome માટે --apps-gallery-url સાથે અલગ પ્રકાશન પ્રોફાઇલ જોઈએ; માર્ગદર્શિકા જુઓ. Edgeને ખાસ વિન્ડો નથી જોઈતી. સ્થાનિક આયાત મફત છે; Sync માટે તે લિસ્ટિંગનું ExtensionTower પેકેજ જોઈએ. Google કે Microsoft સાથે સંકળાયેલું નથી.
