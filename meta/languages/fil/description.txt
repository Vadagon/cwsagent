CWSAgent – Punan at I-export ang Store Listing

Punan at i-export ang Chrome at Edge listing: mga paglalarawan, isinaling screenshot, promo image at sagot sa privacy.

Punan ang iyong listing
Mag-load ng ZIP o folder, o ikonekta ang ExtensionTower at piliin ang Sync. Punan ang suportadong field ng bukas na tab ng store.

Isang pakete. Lahat ng wika.
Pagsamahin ang paglalarawan at screenshot ng bawat wika. Iniaalok ng store ang mga wikang kasama sa na-upload na extension.

Chrome at Edge
Gamitin ang Chrome Web Store console o Microsoft Edge Partner Center. Ikaw mismo ang sumuri at mag-save ng bawat draft.

I-export bago mag-edit
I-export ang teksto at larawan sa Chrome bilang nae-edit na pakete. Opsyonal ang console analytics at mga mensahe sa suporta.

Ikaw ang magse-save
Pinupunan ng CWSAgent ang mga form. Hindi ito awtomatikong nagse-save o nagsusumite, nagche-check ng sertipikasyon o nagpapalit ng presyo at visibility.

Nananatili sa browser ang mga pakete, history at setting. Dina-download sa computer ang mga export. Maaaring personal ang mga mensahe sa suporta: panatilihing pribado ang mga file.

Opsyonal ang ExtensionTower. Nasa IndexedDB ng extension ang API key at background process lang ang gumagamit nito, hindi ang pahina ng store. Binabasa ang listahan at mga pakete sa extensiontower.com; nagda-download din ng larawan ang Sync. Kumokonekta ang extraction sa mga image server ng console. Ginagamit ng mga aksyon ang Google o Microsoft session mo. Walang nakapaloob na analytics o tracking service.

Kailangan ng Chrome ng hiwalay na publishing profile na may --apps-gallery-url; tingnan ang gabay. Walang espesyal na window na kailangan sa Edge. Libre ang lokal na import; kailangan ng Sync ng ExtensionTower package para sa listing. Hindi kaugnay ng Google o Microsoft.
