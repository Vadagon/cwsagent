CWSAgent – กรอกและส่งออกข้อมูลหน้าร้าน

กรอกและส่งออกข้อมูล Chrome และ Edge: คำอธิบาย ภาพหน้าจอที่แปลแล้ว รูปโปรโมต และคำตอบความเป็นส่วนตัว

กรอกข้อมูลหน้าร้าน
โหลด ZIP หรือโฟลเดอร์ หรือเชื่อมต่อ ExtensionTower แล้วเลือก Sync กรอกช่องที่รองรับในแท็บร้านที่เปิดอยู่

แพ็กเกจเดียว ทุกภาษา
เก็บคำอธิบายและภาพหน้าจอแยกตามภาษา ร้านจะแสดงภาษาที่อยู่ในส่วนขยายที่อัปโหลด

Chrome และ Edge
ใช้คอนโซล Chrome Web Store หรือ Microsoft Edge Partner Center ตรวจสอบและบันทึกแต่ละฉบับร่างด้วยตนเอง

ส่งออกก่อนแก้ไข
ส่งออกข้อความและรูปภาพ Chrome เป็นแพ็กเกจที่แก้ไขได้ เลือกส่งออกสถิติคอนโซลและข้อความสนับสนุนได้

คุณเลือกบันทึกเอง
CWSAgent กรอกแบบฟอร์ม ไม่บันทึกหรือส่งอัตโนมัติ ไม่ติ๊กคำรับรอง และไม่เปลี่ยนราคาหรือการแสดงผล

แพ็กเกจ ประวัติ และการตั้งค่าอยู่ในเบราว์เซอร์ ไฟล์ส่งออกจะดาวน์โหลดลงคอมพิวเตอร์ ข้อความสนับสนุนอาจเป็นข้อมูลส่วนตัว โปรดเก็บไฟล์เป็นความลับ

การเชื่อมต่อ ExtensionTower เป็นทางเลือก คีย์ API อยู่ใน IndexedDB ของส่วนขยาย ใช้เฉพาะกระบวนการเบื้องหลังและไม่ส่งให้หน้าร้าน การเชื่อมต่ออ่านรายการและแพ็กเกจจาก extensiontower.com และ Sync ดาวน์โหลดรูปภาพด้วย การดึงภาพติดต่อเซิร์ฟเวอร์ภาพของคอนโซล การทำงานใช้เซสชัน Google หรือ Microsoft ของคุณ ไม่มีบริการวิเคราะห์หรือติดตามในตัว

Chrome ต้องใช้โปรไฟล์เผยแพร่แยกที่เริ่มด้วย --apps-gallery-url โปรดดูคู่มือ Edge ไม่ต้องใช้หน้าต่างพิเศษ การนำเข้าในเครื่องฟรี ส่วน Sync ต้องมีแพ็กเกจ ExtensionTower สำหรับรายการนั้น ไม่เกี่ยวข้องกับ Google หรือ Microsoft
