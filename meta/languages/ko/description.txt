CWSAgent – 스토어 등록 정보 자동 입력 및 추출

Chrome과 Edge 등록 정보를 입력하고 내보내세요. 설명, 번역된 스크린샷, 홍보 이미지, 개인정보 답변을 지원합니다.

등록 정보를 채우세요
ZIP이나 폴더를 불러오거나 ExtensionTower에 연결한 뒤 Sync를 선택하세요. 열린 스토어 탭의 지원 필드를 입력합니다.

하나의 패키지로 모든 언어
언어별 설명과 스크린샷을 함께 관리하세요. 스토어는 업로드한 확장 프로그램에 포함된 언어를 제공합니다.

Chrome과 Edge
Chrome Web Store 개발자 콘솔 또는 Microsoft Edge Partner Center를 사용하세요. 각 초안을 직접 검토하고 저장하세요.

수정 전에 내보내기
Chrome 텍스트와 이미지를 편집 가능한 패키지로 내보내세요. 콘솔 통계와 지원 메시지는 선택 사항입니다.

저장은 직접 결정하세요
CWSAgent는 양식을 채웁니다. 자동 저장·제출, 인증 확인, 가격이나 공개 범위 변경은 하지 않습니다.

패키지, 기록, 설정은 브라우저 저장소에 남습니다. 내보낸 파일은 컴퓨터에 다운로드됩니다. 지원 메시지에는 개인정보가 있을 수 있으니 비공개로 보관하세요.

ExtensionTower 연결은 선택 사항입니다. API 키는 확장 프로그램의 IndexedDB에 저장되며 백그라운드 작업만 사용하고 스토어 페이지에 보내지 않습니다. extensiontower.com에서 확장 프로그램 목록과 패키지를 읽으며 Sync는 이미지도 다운로드합니다. 이미지 추출은 콘솔 이미지 서버에 접속합니다. 스토어 작업은 본인의 Google 또는 Microsoft 세션을 사용합니다. 분석·추적 서비스는 통합되어 있지 않습니다.

Chrome은 --apps-gallery-url로 시작한 별도 게시 프로필이 필요합니다. 설치 안내를 참고하세요. Edge는 별도 창이 필요 없습니다. 로컬 가져오기는 무료이며 Sync는 해당 등록 정보의 ExtensionTower 패키지가 필요합니다. Google 또는 Microsoft와 관련이 없습니다.
