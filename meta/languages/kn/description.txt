CWSAgent – ಸ್ಟೋರ್ ಪಟ್ಟಿ ಭರ್ತಿ ಮತ್ತು ರಫ್ತು

Chrome ಮತ್ತು Edge ಪಟ್ಟಿಗಳನ್ನು ಭರ್ತಿ ಮಾಡಿ ರಫ್ತು ಮಾಡಿ: ವಿವರಣೆ, ಅನುವಾದಿತ ಸ್ಕ್ರೀನ್‌ಶಾಟ್, ಪ್ರಚಾರ ಚಿತ್ರ ಮತ್ತು ಗೌಪ್ಯತಾ ಉತ್ತರಗಳು.

ನಿಮ್ಮ ಪಟ್ಟಿಯನ್ನು ಭರ್ತಿ ಮಾಡಿ
ZIP ಅಥವಾ ಫೋಲ್ಡರ್ ಲೋಡ್ ಮಾಡಿ ಅಥವಾ ExtensionTower ಜೋಡಿಸಿ Sync ಆಯ್ಕೆಮಾಡಿ. ತೆರೆದ ಸ್ಟೋರ್ ಟ್ಯಾಬ್‌ನ ಬೆಂಬಲಿತ ಕ್ಷೇತ್ರಗಳನ್ನು ಭರ್ತಿ ಮಾಡಿ.

ಒಂದು ಪ್ಯಾಕೇಜ್. ಎಲ್ಲ ಭಾಷೆಗಳು.
ಪ್ರತಿ ಭಾಷೆಯ ವಿವರಣೆ ಮತ್ತು ಚಿತ್ರಗಳನ್ನು ಒಟ್ಟಿಗೆ ಇಡಿ. ಅಪ್‌ಲೋಡ್ ಮಾಡಿದ ವಿಸ್ತರಣೆಯ ಭಾಷೆಗಳನ್ನು ಸ್ಟೋರ್ ಒದಗಿಸುತ್ತದೆ.

Chrome ಮತ್ತು Edge
Chrome Web Store ಕನ್ಸೋಲ್ ಅಥವಾ Microsoft Edge Partner Center ಬಳಸಿ. ಪ್ರತಿ ಕರಡನ್ನು ನೀವೇ ಪರಿಶೀಲಿಸಿ ಉಳಿಸಿ.

ತಿದ್ದುಪಡಿ ಮೊದಲು ರಫ್ತು ಮಾಡಿ
Chrome ಪಠ್ಯ ಮತ್ತು ಚಿತ್ರಗಳನ್ನು ಸಂಪಾದಿಸಬಹುದಾದ ಪ್ಯಾಕೇಜ್‌ಗೆ ರಫ್ತು ಮಾಡಿ. ಕನ್ಸೋಲ್ ಅಂಕಿಅಂಶಗಳು ಮತ್ತು ಬೆಂಬಲ ಸಂದೇಶಗಳು ಐಚ್ಛಿಕ.

ಕೊನೆಯ ಉಳಿಸುವಿಕೆ ನಿಮ್ಮದು
CWSAgent ಫಾರ್ಮ್‌ಗಳನ್ನು ಭರ್ತಿ ಮಾಡುತ್ತದೆ. ಸ್ವಯಂ ಉಳಿಸುವುದಿಲ್ಲ ಅಥವಾ ಸಲ್ಲಿಸುವುದಿಲ್ಲ, ಪ್ರಮಾಣೀಕರಣ ಆಯ್ಕೆ ಮಾಡುವುದಿಲ್ಲ, ಬೆಲೆ ಅಥವಾ ಗೋಚರತೆಯನ್ನು ಬದಲಿಸುವುದಿಲ್ಲ.

ಪ್ಯಾಕೇಜ್, ಇತಿಹಾಸ ಮತ್ತು ಸೆಟ್ಟಿಂಗ್‌ಗಳು ಬ್ರೌಸರ್‌ನಲ್ಲಿ ಉಳಿಯುತ್ತವೆ. ರಫ್ತು ಕಡತಗಳು ಕಂಪ್ಯೂಟರ್‌ಗೆ ಇಳಿಯುತ್ತವೆ. ಬೆಂಬಲ ಸಂದೇಶಗಳು ಖಾಸಗಿಯಾಗಿರಬಹುದು: ಕಡತಗಳನ್ನು ಖಾಸಗಿಯಾಗಿ ಇಡಿ.

ExtensionTower ಸಂಪರ್ಕ ಐಚ್ಛಿಕ. API ಕೀ ವಿಸ್ತರಣೆಯ IndexedDBಯಲ್ಲಿ ಇರುತ್ತದೆ ಮತ್ತು ಹಿನ್ನೆಲೆ ಪ್ರಕ್ರಿಯೆ ಮಾತ್ರ ಬಳಸುತ್ತದೆ, ಸ್ಟೋರ್ ಪುಟವಲ್ಲ. ಸಂಪರ್ಕ extensiontower.comನಿಂದ ಪಟ್ಟಿ ಮತ್ತು ಪ್ಯಾಕೇಜ್ ಓದುತ್ತದೆ; Sync ಚಿತ್ರಗಳನ್ನೂ ಇಳಿಸುತ್ತದೆ. ಚಿತ್ರ ರಫ್ತು ಕನ್ಸೋಲ್‌ನ ಚಿತ್ರ ಸರ್ವರ್‌ಗಳನ್ನು ಸಂಪರ್ಕಿಸುತ್ತದೆ. ಕ್ರಿಯೆಗಳು ನಿಮ್ಮ Google ಅಥವಾ Microsoft ಸೆಷನ್ ಬಳಸುತ್ತವೆ. ವಿಶ್ಲೇಷಣೆ ಅಥವಾ ಟ್ರ್ಯಾಕಿಂಗ್ ಸೇವೆ ಸೇರಿಸಿಲ್ಲ.

Chromeಗೆ --apps-gallery-urlನೊಂದಿಗೆ ಪ್ರತ್ಯೇಕ ಪ್ರಕಟಣಾ ಪ್ರೊಫೈಲ್ ಬೇಕು; ಮಾರ್ಗದರ್ಶಿ ನೋಡಿ. Edgeಗೆ ವಿಶೇಷ ಕಿಟಕಿ ಬೇಡ. ಸ್ಥಳೀಯ ಆಮದು ಉಚಿತ; Syncಗೆ ಆ ಪಟ್ಟಿಯ ExtensionTower ಪ್ಯಾಕೇಜ್ ಬೇಕು. Google ಅಥವಾ Microsoftಗೆ ಸಂಬಂಧಿಸಿಲ್ಲ.
