ലിസ്റ്റിംഗ് പൂരിപ്പിക്കൂ
ZIP അല്ലെങ്കിൽ ഫോൾഡർ ലോഡ് ചെയ്യുക, അല്ലെങ്കിൽ ExtensionTower ബന്ധിപ്പിച്ച് Sync തിരഞ്ഞെടുക്കുക. തുറന്ന സ്റ്റോർ ടാബിലെ പിന്തുണയുള്ള ഫീൽഡുകൾ പൂരിപ്പിക്കുക.

ഒരു പാക്കേജ്. എല്ലാ ഭാഷകളും.
ഓരോ ഭാഷയുടെയും വിവരണവും ചിത്രങ്ങളും ഒരുമിച്ച് സൂക്ഷിക്കുക. അപ്‌ലോഡ് ചെയ്ത വിപുലീകരണത്തിലെ ഭാഷകളാണ് സ്റ്റോർ നൽകുന്നത്.

Chrome, Edge
Chrome Web Store കൺസോൾ അല്ലെങ്കിൽ Microsoft Edge Partner Center ഉപയോഗിക്കുക. ഓരോ കരടും സ്വയം പരിശോധിച്ച് സേവ് ചെയ്യുക.

തിരുത്തും മുമ്പ് കയറ്റുമതി
Chrome എഴുത്തും ചിത്രങ്ങളും തിരുത്താവുന്ന പാക്കേജിലേക്ക് കയറ്റുമതി ചെയ്യുക. കൺസോൾ കണക്കുകളും പിന്തുണാ സന്ദേശങ്ങളും ഐച്ഛികമാണ്.

അവസാന സേവ് നിങ്ങളുടേത്
CWSAgent ഫോമുകൾ പൂരിപ്പിക്കുന്നു. സ്വയം സേവ് ചെയ്യുകയോ സമർപ്പിക്കുകയോ സർട്ടിഫിക്കേഷൻ അടയാളപ്പെടുത്തുകയോ വിലയും ദൃശ്യതയും മാറ്റുകയോ ചെയ്യില്ല.

പാക്കേജുകളും ചരിത്രവും ക്രമീകരണങ്ങളും ബ്രൗസറിൽ തുടരും. കയറ്റുമതി ഫയലുകൾ കമ്പ്യൂട്ടറിൽ ഡൗൺലോഡ് ചെയ്യും. പിന്തുണാ സന്ദേശങ്ങൾ സ്വകാര്യമായിരിക്കാം: ഫയലുകൾ രഹസ്യമായി സൂക്ഷിക്കുക.

ExtensionTower ബന്ധം ഐച്ഛികമാണ്. API കീ വിപുലീകരണത്തിന്റെ IndexedDBയിൽ സൂക്ഷിക്കുകയും പശ്ചാത്തല പ്രക്രിയ മാത്രം ഉപയോഗിക്കുകയും ചെയ്യുന്നു; സ്റ്റോർ പേജിന് നൽകില്ല. ബന്ധം extensiontower.comൽ നിന്ന് പട്ടികയും പാക്കേജുകളും വായിക്കുന്നു; Sync ചിത്രങ്ങളും ഡൗൺലോഡ് ചെയ്യുന്നു. ചിത്രം കയറ്റുമതി കൺസോളിന്റെ ചിത്ര സെർവറുകളുമായി ബന്ധപ്പെടുന്നു. പ്രവർത്തനങ്ങൾ നിങ്ങളുടെ Google അല്ലെങ്കിൽ Microsoft സെഷൻ ഉപയോഗിക്കുന്നു. അനലിറ്റിക്സ് അല്ലെങ്കിൽ ട്രാക്കിംഗ് സേവനം ചേർത്തിട്ടില്ല.

Chromeന് --apps-gallery-url ഉപയോഗിച്ചുള്ള പ്രത്യേക പ്രസിദ്ധീകരണ പ്രൊഫൈൽ വേണം; ഗൈഡ് കാണുക. Edgeന് പ്രത്യേക വിൻഡോ വേണ്ട. പ്രാദേശിക ഇറക്കുമതി സൗജന്യം; Syncന് ആ ലിസ്റ്റിംഗിന്റെ ExtensionTower പാക്കേജ് വേണം. Google, Microsoft എന്നിവയുമായി ബന്ധമില്ല.
