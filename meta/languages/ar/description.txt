CWSAgent – تعبئة واستخراج صفحات المتاجر

املأ وصدّر صفحات Chrome وEdge: الأوصاف ولقطات الشاشة المترجمة والصور الترويجية وإجابات الخصوصية.

املأ صفحة متجرك
حمّل ZIP أو مجلدًا، أو اربط ExtensionTower واختر Sync. املأ الحقول المدعومة في علامة تبويب المتجر المفتوحة.

حزمة واحدة. كل اللغات.
احتفظ بالوصف ولقطات الشاشة معًا لكل لغة. يعرض المتجر اللغات الموجودة في الإضافة المرفوعة.

Chrome وEdge
استخدم لوحة Chrome Web Store أو Microsoft Edge Partner Center. راجع كل مسودة واحفظها بنفسك.

صدّر قبل التعديل
صدّر نصوص Chrome وصوره إلى حزمة قابلة للتعديل. إحصاءات اللوحة ورسائل الدعم اختيارية.

أنت تقرر الحفظ
يملأ CWSAgent النماذج. لا يحفظ أو يرسل تلقائيًا، ولا يحدد إقرارات الاستخدام أو يغيّر الأسعار والظهور.

تبقى الحزم والسجل والإعدادات في تخزين المتصفح. تُنزّل الملفات إلى حاسوبك. قد تتضمن رسائل الدعم بيانات شخصية، فاحفظها بشكل خاص.

ربط ExtensionTower اختياري. يبقى مفتاح API في IndexedDB الخاصة بالإضافة وتستخدمه عملية الخلفية فقط، ولا يصل إلى صفحة المتجر. يقرأ الاتصال قائمة إضافاتك وحزمها من extensiontower.com؛ وينزّل Sync الصور أيضًا. يتصل استخراج الصور بخوادم صور اللوحة. تستخدم العمليات جلستك في Google أو Microsoft. لا توجد خدمة تحليلات أو تتبع مدمجة.

يتطلب Chrome ملف نشر منفصلًا يبدأ مع --apps-gallery-url؛ راجع دليل التثبيت. لا يحتاج Edge نافذة خاصة. استيراد الحزم المحلية مجاني؛ يتطلب Sync حزمة ExtensionTower لهذه الصفحة. غير تابع لـGoogle أو Microsoft.
